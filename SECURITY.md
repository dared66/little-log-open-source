# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not include access tokens, real baby records, Drive file links, or other family
data in a report. If private reporting is unavailable, open a brief issue that
asks a maintainer for a private contact channel without publishing exploit
details.

Include the affected version, platform, reproduction steps using synthetic
data, and the security impact. Maintainers will acknowledge a report as soon as
practical and coordinate disclosure after a fix is available.

## Supported versions

Until Little Log has a stable release, security fixes are made on the latest
commit on the default branch only.
